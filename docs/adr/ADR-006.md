# ADR-006: Adapter Isolation

**Status**: Accepted
**Date**: 2026-02-18

## Context

Both adapters (`css.ts` and `tailwind-v4.ts`) navigate the token tree structure directly:
```typescript
if (tokens.primitive?.color) { ... }
if (tokens.primitive?.spacing) { ... }
```
This couples adapters to the exact shape of `DTCGRoot`. Adding a `component` token layer (as the whitepaper's 4-layer model requires) would require modifying every adapter.

Additionally, only two of the four planned adapters exist (CSS, Tailwind). JSON Schema export and CLI are referenced in the README but not implemented.

The `prefix` option in the Tailwind adapter is partially broken — it applies to `:root` semantic tokens but not to `@theme` block entries.

## Decision

**Rule**: Adapters operate on a flat token list, not the tree structure.

Add to `@syncupsuite/tokens`:
```typescript
export function flattenRoot(tokens: DTCGRoot): Array<{
  path: string[];
  token: DTCGToken;
  layer: 'primitive' | 'semantic' | 'component';
  mode?: 'light' | 'dark';
}>;
```

All adapters consume this flat list. They filter by `layer` to decide what to include (e.g., Tailwind adapter puts `primitive` layer in `@theme`, `semantic.light` in `:root`). Tree structure navigation disappears from adapters entirely.

**Four adapters target**:
1. `transformToCSS` — existing, refactored ✓
2. `transformToTailwindV4` — existing, refactored ✓
3. `transformToJSON` — new, exports flat token list as DTCG-compliant JSON. Used for Figma plugin, Style Dictionary bridge.
4. `transformToCLI` — new, outputs a `tokens.env` file of shell-friendly variable names for use in build scripts

**Fix prefix bug**: Apply `prefix` to `@theme` entries in the Tailwind adapter.

## Consequences

**Positive**:
- Adding a `component` layer to `DTCGRoot` requires no adapter changes
- New adapters can be added with ~50 lines each — just filter and format the flat list
- `prefix` option works correctly in all adapters
- JSON export enables Figma plugin integration (gt-dg004)

**Negative**:
- `flattenRoot` is a new function in `tokens` — adds surface area to the leaf package
- Refactoring both existing adapters carries regression risk (mitigated by snapshot matrix, ADR-005)
- The flat list loses tree-level grouping that `@theme` currently uses for section comments
