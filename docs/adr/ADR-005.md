# ADR-005: CI Snapshot Matrix

**Status**: Accepted — implement before themes 3-10
**Date**: 2026-02-18

## Context

The `PERF_BUDGETS` constants in `constants.ts` define `maxCssGzipped: 20_480` and `maxProperties: 500` but no code enforces them. The `contrast: true` flag in `generate-themes.ts` is hardcoded with a `// TODO: full contrast audit` comment — no actual contrast check is performed. The published `meta.json` for each theme claims `validation.contrast: true` which is misleading.

At 10 themes, adding themes without automated visual regression creates significant regression risk — especially for the OKLCH migration (ADR-001) which will change all numeric token values.

## Decision

**Two components**:

### 1. Build-time budget enforcement
Add to the generation script (`generate-themes.ts`):
```typescript
const cssGzipped = gzipSync(Buffer.from(tailwindCss)).length;
if (cssGzipped > PERF_BUDGETS.maxCssGzipped) {
  throw new Error(`Theme ${name} exceeds CSS budget: ${cssGzipped}B > ${PERF_BUDGETS.maxCssGzipped}B`);
}
const propertyCount = (css.match(/--[\w-]+:/g) || []).length;
if (propertyCount > PERF_BUDGETS.maxProperties) {
  throw new Error(`Theme ${name} exceeds property budget: ${propertyCount} > ${PERF_BUDGETS.maxProperties}`);
}
```
Also remove `contrast: true` hardcoding — either compute it or set `contrast: null` (unverified).

### 2. Visual snapshot matrix in CI
- Tool: Playwright (headless) — generate a test HTML page per theme per mode
- Matrix: `themes (10) × modes (light, dark) = 20 snapshots`
- Storage: commit baselines to repo under `snapshots/`
- Trigger: run on every PR; fail if pixel diff > threshold
- Local: `pnpm snapshots` generates/updates baselines

Each snapshot page renders the full component preview (buttons, cards, inputs, badges, typography) using the theme's CSS import.

## Consequences

**Positive**:
- OKLCH migration (ADR-001) cannot silently break visual output
- Performance budgets are enforced, not aspirational
- WCAG contrast can be computed and truthfully reported in `meta.json`
- New theme contributors get immediate visual feedback

**Negative**:
- Playwright adds to CI runtime (~30s per run estimated at 20 snapshots)
- Baseline snapshots are binary files in the repo (~200KB per theme)
- Initial setup effort for the snapshot HTML template
